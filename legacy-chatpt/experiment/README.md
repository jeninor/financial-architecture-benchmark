# Registro de prompts

Os prompts deste diretório são classificados em três categorias:

## Historical

Prompt preservado conforme utilizado durante o desenvolvimento.
Não deve ser modificado após a execução.

## Reconstructed

Prompt reconstruído posteriormente com base nos registros,
conversas, código e decisões efetivamente realizadas durante o
experimento.

Não representa necessariamente o texto exato utilizado originalmente.

## Post-experiment analysis

Prompt criado após a implementação para revisão, análise ou
elaboração do trabalho acadêmico.

Não deve ser contabilizado como evidência do processo original de
desenvolvimento.

Atualmente:

M02_quote_buy_portfolio = Historical
M03_integration_tests = Historical

Os demais prompts devem receber a classificação correspondente
conforme sua data efetiva de execução.
