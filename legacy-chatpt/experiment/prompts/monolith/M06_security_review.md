Realize uma revisão de segurança da implementação concluída.

Não altere o código nesta etapa.

Analise somente riscos que possam ser sustentados pelo código
fornecido.

Verifique, entre outros:

- validação de entrada;
- exposição indevida de erros;
- configuração de banco de dados;
- credenciais em configuração;
- tratamento de dados;
- endpoints REST;
- dependências;
- configuração de containers.

Classifique cada achado como:

- confirmado;
- potencial;
- não aplicável.

Não classifique automaticamente a aplicação como insegura.
Não invente vulnerabilidades.

Para cada achado informe:

componente
categoria
evidência
impacto potencial
recomendação
