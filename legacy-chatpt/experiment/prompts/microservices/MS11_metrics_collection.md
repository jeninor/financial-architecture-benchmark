métricas estruturais utilizadas no monólito.

discovery-server

- Physical Java LOC;
- número de arquivos Java;
- Lizard NLOC;
- métodos/funções;
- CC total;
- CC médio;
- CC máximo;
- número de testes;
- testes aprovados;
- failures;
- errors.

Também apresentar LOC e arquivos por componente.

monólito.
